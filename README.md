# SE5 Lab 2 - Refactoring

This is a simple Flutter source-code project prepared for Lab 2 Refactoring.

## Main source files
- lib/main.dart
- lib/models/pwd.dart
- lib/services/pwd_service.dart
- lib/screens/pwd_list_page.dart
- lib/utils/app_constants.dart

The project separates the model, service, screen, and constants to demonstrate basic refactoring and cleaner organization.
